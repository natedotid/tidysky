# Security

TidySky is a client-side app with no backend, but if you find a security
problem, for example a way to exfiltrate the data stored in a browser, or a
misconfiguration that exposes something, please report it privately.

## Reporting

Use the **Security** tab on this repository (GitHub's private
vulnerability reporting) rather than a public issue.

## Scope

This project is the TidySky web app and this repository only. Problems in
Bluesky itself, the atproto protocol, or third-party services (for example
Fathom) are out of scope: report those to the respective projects.
